# 실험 메모

입력 축을 `(sample, time, channel)`로 수정하고 정규화를 학습 데이터에만 맞췄습니다.
Transformer 출력은 시간축 평균으로 모읍니다. 클래스별 지표와 macro F1을 함께 저장하도록 바꿨습니다.

LIME은 전체 시계열을 펼친 뒤 같은 모양으로 복원해 예측합니다. 피처 번호는 조건문에서 추측하지 않고 `as_map()`으로 받습니다.
SHAP과 IG는 학습 데이터에서 고른 background를 사용하며 결과를 시간×채널 그림으로 저장합니다.
두 데이터셋에서 각각 두 시험 샘플의 세 설명 기법을 실제 실행했습니다.

`results/current/`는 수정 후 실행 결과입니다. `historical_*`는 이전 과제의 출력으로, 입력 구조와 설정이 달라 직접 비교하지 않습니다.
시험셋을 별도 검증셋처럼 반복 사용해 모델을 선택하지 않았고, 여러 seed의 성능 변동은 이번 실험에서 측정하지 않았습니다.
